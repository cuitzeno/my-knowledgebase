# 宏与扩展：会话处理宏、Cookie Jar、实用插件

## 一句话定义
用 **宏(Macro)** 录制登录/取 Token 流程自动维持会话，**Cookie Jar** 统一管理凭证，**BApp Store 扩展** 给 Burp 加外挂能力(增强扫描/解码/专用攻击面)。

## 核心架构 / 工作原理

```mermaid
graph TD
  A[自动化会话维持] --> B[会话处理宏 Session Handling Macro]
  B --> B1[录制: 登录 -> 取 Token/Session -> 写入变量]
  B --> B2[规则: Session Handling Rules -> Before request 执行宏]
  B --> B3[变量替换: 宏提取值 -> {{macro_token}} -> 后续请求自动带上]
  
  A --> C[Cookie Jar]
  C --> C1[收集: 所有响应 Set-Cookie 自动入罐]
  C --> C2[复用: Repeater/Scanner/Intruder 勾选 Use cookies from jar]
  C --> C3[跨工具共享: 同一 Session ID 多工具同步]
  
  A --> D[BApp Store 扩展]
  D --> D1[扫描增强: Active Scan++ / Custom Scan Checks]
  D --> D2[解码/编码: JWT Editor / SAML Raider / Crypto]
  D --> D3[认证辅助: OAuth / SAML / Kerberos / NTLM]
  D --> D4[攻击面: GraphQL / WebSocket / HTTP/2 / gRPC]
  D --> D5[工具: Logger++ / Flow / Retire.js / Software Vulnerability Scanner]
```

| 组件 | 配置入口 | 核心作用 | 典型场景 |
|------|----------|----------|----------|
| **宏** | Project options → Sessions → Macros | 自动执行一串请求、提取动态值 | 登录拿 Token、OAuth 刷新 Token、CSRF Token 更新 |
| **Session Handling Rules** | Project options → Sessions → Session Handling Rules | 绑定宏到工具/URL/条件 | 所有请求前自动跑登录宏、只对 Scope 内请求 |
| **Cookie Jar** | Project options → Sessions → Cookie Jar | 集中存储/分发 Cookie | 扫描/Intruder/Repeater 自动带最新 Cookie |
| **扩展** | Extender → BApp Store | 扩展 Burp 原生能力 | Active Scan++ 增强扫描、JWT Editor 解码改签、Logger++ 增强日志 |

## 快速上手步骤

1. **建登录宏**：
   - Project options → Sessions → Macros → Add → 录制：
     1. GET 登录页(拿 CSRF Token)
     2. POST 登录(用户名/密码/CSRF)
     3. GET 需认证的页面/接口(验证登录态)
   - 测试宏：Run macro → 看每步响应 OK → 最后一步提取 Session Cookie/Token 到变量
2. **绑定会话规则**：
   - Session Handling Rules → Add → Rule Actions → Run a macro → 选刚建的宏
   - Scope: "All tools" / "Only in-scope items" / "URL regex"
   - 勾选 "Before request" → 保存
3. **启用 Cookie Jar**：
   - Project options → Sessions → Cookie Jar → 勾选 "Use cookies from the cookie jar"
   - 可选：定义 Cookie Jar 规则(域名/路径/过期策略)
4. **装实用插件**：
   - Extender → BApp Store → 搜索安装：
     - **Active Scan++** — 增强主动扫描规则(模板注入、SSRF、XXE 等)
     - **JWT Editor** — JWT 解码/编辑/重签(HS256/RS256/none/弱密钥爆破)
     - **Logger++** — 彩色高亮/过滤/导出 HTTP 历史
     - **Software Vulnerability Scanner** — 组件版本识别+已知 CVE
     - **Retire.js** — 前端 JS 库漏洞扫描
     - **GraphQL Raider / WebSocket / HTTP/2** — 协议支持
     - **AuthMatrix / AuthAnalyzer** — 授权矩阵自动化测试
5. **赏金/实战技巧**：
   - 用扩展快速验证特定漏洞类(如 JWT Editor 测 alg=none/弱密钥)
   - 宏 + Cookie Jar + 扫描器 = 全自动带认证扫描
   - Logger++ 导出历史 → 离线分析/报证据

## 踩坑避坑指南

| 场景 | 问题现象 | 原因 | 解决/最佳实践 |
|------|----------|------|---------------|
| 宏录一次以为永久有效 | 目标改登录流程/Token 名变了 | 宏是静态录制 | **目标变更即重录**；用变量提取而非硬编码；定期跑宏验证 |
| 插件装太多拖慢/报错 | 启动慢、扫描异常、内存爆 | 冲突/版本不兼容/资源争抢 | **按需启用**；核心插件锁定版本；出问题二分法禁用排查 |
| 靠宏绕过权限测试 | 宏只管会话维持，越权还得手测 | 认知偏差 | 宏解决"怎么保持登录"，**不解决"能不能越权"** |
| Cookie Jar 不生效 | Repeater/Scanner 没带 Cookie | 未勾选/域名不匹配/过期 | 检查：勾选 Use cookies from jar、域名匹配、Cookie 未过期、SameSite 策略 |
| 扩展更新后不兼容 | Burp 版本升级插件挂 | API 变更 | 生产环境锁定 Burp+插件版本；测试环境先升级验证 |

## 替代方案对比

| 维度 | Burp 宏+扩展 | OWASP ZAP 脚本/插件 | 代码/脚本自动化 | 专用工具 |
|------|--------------|---------------------|-----------------|----------|
| 会话维持成熟度 | ✅ 宏+规则+Jar 完善 | ✅ Authentication/Script | ✅ 完全可控 | ❌ 无 |
| 扩展生态丰富度 | ✅ BApp Store 数百个 | ✅ Marketplace 丰富 | ❌ 无 | ❌ 无 |
| 赏金实战适配 | ✅ JWT/Active Scan++/AuthMatrix | ⚠️ 需配置 | ✅ 定制最强 | ✅ 专用强 |
| 维护成本 | 中(图形化配置) | 中(脚本/配置) | 高(代码维护) | 低(开箱即用) |
