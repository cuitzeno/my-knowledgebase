# 文章模板（单篇）

每篇文章严格按以下结构生成（通俗讲解 + 知识点详解）：

```
# <主题·序号>｜<吸引人的标题>

<一句导语：用大白话说这一篇解决什么困惑。>

## ① 是什么
<用最通俗的话定义这个概念，避免一上来堆术语。>

## ② 为什么重要
<讲清它在实际中/考试/工作里的意义，最好点出"不懂会怎样"。>

## ③ 核心概念拆解
<拆成 1–3 个知识点，每个配一个生活类比或具体例子，务必好懂。>
- **知识点 A**：…（类比：…）
- **知识点 B**：…（例子：…）

## ④ 常见误区
<列 2–3 个新手最容易搞混的点，逐条澄清。>

## ⑤ 一句话小结
<用一句话把全篇收住。>

*下一篇：<下一篇标题>*

> 参考来源：<素材文件名>（本文为原创讲解，非转载原文）
```

规则：
- 全篇简体中文，口语化、通俗易懂。
- 篇幅 800–1500 字，聚焦 1–3 个概念。
- ③④ 为硬性段落，不可省略。
- 末句"下一篇"在生成索引后回填（最后一篇写"系列完"）。
