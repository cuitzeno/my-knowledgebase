# ① 一句话秒懂

培训、意识与文档（Training, Awareness & Documentation）是 DRP 落地的最后一公里：按角色分层培训全员、把计划当**极敏感文档**按 need-to-know 分发（用活页夹/内网但备纸质副本），确保灾难时人人知道自己干啥、计划拿得到。

# ② 生活类比

DRP 是"地震应急手册"：新兵入职发一页（orientation），新上岗的 DR 角色做专门培训，老队员定期 refresher，其他员工邮件简报扫盲。手册本身是国家机密级——只给该知道的人看对应部分，关键成员才看全本；且内网可能灾时挂，所以主/备站点都得放**最新纸质版**。

# ③ 核心概念

## 培训计划要素（按角色分层）
- **Orientation（入职导向）**：所有新员工。
- **Initial training（初始培训）**：首次担任 DR 角色的员工。
- **Detailed refresher（详细复训）**：DR 团队成员。
- **Brief awareness refresher（简要意识复训）**：其他员工，可并入其他会议或邮件简报。

## 文档化（Documentation）
DRP 须完整文档化，并随计划变更修改。因变化快，可发布在**安全内网分区**；但 DRP 是**极敏感文档**，按 **compartmentalized、need-to-know** 仅分发给个人——参与人员懂自己角色即可，不需也不该看全本。关键 DR 成员与高管须能访问全本。

> 重要：灾难可能让**内网不可用**。若用内网分发，须在主站点与备用站点都保留**足够数量的纸质最新副本**，且只保留最新版！

## 活页夹（Loose-leaf binders）
适合存 DRP——单页变更分发即可，不必重印整本。

# ④ 真实案例

某组织把 DRP 只放内网，结果区域性灾难把内网也打挂了，现场人员手里没计划、一片混乱。原书强调：无论用什么电子分发，主/备站点都必须有**纸质最新副本**——因为灾难恰恰最可能让电子系统失效，而那时恰恰最需要用计划。

# ⑤ 考试怎么考

- 培训四层（orientation / initial / refresher / awareness）。
- DRP 是**极敏感文档**，按 need-to-know/compartmentalized 分发；关键成员+高管看全本。
- **内网可能灾时不可用** → 主备站点须备纸质最新副本。
- 活页夹便于单页更新。

# ⑥ 记忆口诀

> **"培训四层按角分：导向初始复训意识；DRP 极敏需知发，内网灾挂纸备份，主备站点最新本。"**
