# ① 一句话秒懂

恢复策略（Recovery Strategy）先按 BIA 排优先级恢复关键业务单元/功能，再选备用处理站点（冷/温/热/移动/云）、签互助协议（MAA），并用电子保管/远程日志/远程镜像三种数据库复制技术满足 RPO。

# ② 生活类比

- **Cold Site（冷站）** = 租了空仓库，啥设备没有，灾后要自己搬机器、拉线、恢复数据——几周才就绪。
- **Warm Site（温站）** = 设备线路现成，但没你的数据，运备份过去半天（≥12 小时）能跑。
- **Hot Site（热站）** = 全镜像 replica，数据实时同步，秒级接管——但贵到翻倍预算。
- **MAA（互助协议）** = 和邻居约定"你灾了我让你用我机房"，省钱但靠信任、怕同灾、怕泄密。

# ③ 核心概念

## 业务单元与功能优先级
基于 **BIA（业务影响分析）** 排恢复顺序。关键业务单元 ≠ 所有关键功能都在关键单元，最终是"关键单元 + 其他精选单元"的超集。可先恢复高优先级单元到 50% 能力，再铺低优先级到最低运营能力，最后全面恢复。结合指标：**MTTR、MTD、RTO、RPO**（Ch3）。

## 危机管理（Crisis Management）
恐慌时常识会忘（如火灾打 911）。靠持续培训；关键员工能现场领导。覆盖一切危机（火灾到大流行到公关灾难）。

## 应急通信（Emergency Communications）
内部+外部都要能通。员工须把媒体问询转交 PR 团队（别由员工乱说）。灾难可能已毁正常通信，须**提前**备替代通信。

## 工作组恢复（Workgroup Recovery）
DRP 目标是恢复工作组到常态工作点，不止 IT。可为不同工作组设独立恢复设施。

## 备用处理站点（Alternate Processing Sites）
- **Cold Site（冷站）**：够大、有电与环境系统，但**无预装计算设备、无激活宽带**。最便宜，激活以**周**计，难测试，易给虚假安全感。
- **Hot Site（热站）**：全配置、数据周期/连续复制到热站。可瞬时/秒级接管；贵（近乎双倍预算+额外人力）。注意：热站有生产数据副本，**须与主站同等安全**。可共享（怕大灾时过载）或兼作开发/测试环境降本。
- **Warm Site（温站）**：有设备与数据电路但**通常无客户数据**；运备份介质恢复，激活 ≥12 小时。可共享，合同须写"no lockout"条款。
- **Mobile Site（移动站）**：自带环境的拖车，fly-away 部署；常配成冷/温站，适合作工作组恢复。
- **Cloud Computing**：IaaS（AWS/Azure/GCP）成本低、激活前几乎不花运维钱；须考虑资源容量协议（resource capacity agreement）、地理分散、冗余。

## 硬件替换选项
- **In-house 替换**：在异地附近仓库存备用设备，立即可取。
- **Vendor SLA**：4/12/24/48 小时替换合同——但交付不保证，不可作为唯一恢复手段。

## Mutual Assistance Agreements (MAA / Reciprocal)
两组织互帮共享设施，省资本。缺点：难强制执行（灾时对方可能反悔）、地理近则同灾、保密顾虑（医疗/金融/商业秘密）。同组织内部子公司间较可行。

## 数据库恢复三技术（按 RPO 选）
1. **Electronic Vaulting（电子保管）**：批量把 DB 备份传到异地。**恢复延迟大**，仅能恢复到**上次保管时**——潜在显著数据丢失。合同须写明定义/容量/带宽/取数时间。
2. **Remote Journaling（远程日志）**：更频繁（通常每小时）传**事务日志**（非整库），灾时应用日志到生产库。仍存于备份设备未实时应用。
3. **Remote Mirroring（远程镜像）**：最先进最贵，异地保**活数据库服务器**，修改实时同步，随时可接管。增处理开销。云数据库平台常内置冗余。

# ④ 真实案例

某组织用热站又想省钱，把热站兼作开发/测试环境——实时把生产数据复制到热站既供测试又留活副本，让热站"不灾时也有用"，摊薄了高昂成本。这是热站降本的常见实战技巧。

# ⑤ 考试怎么考

- **冷/温/热站**区别（有无设备、有无数据、激活时间、成本）：冷=周、温≥12h、热=秒/分。
- **热站有生产数据副本 → 须同等安全控制**。
- **MAA** 三缺点（难强制、同灾、保密）。
- 数据库三技术对应 RPO 激进度：mirroring（实时）> journaling（每小时日志）> vaulting（批量，丢失最大）。
- 优先级基于 BIA；RTO/RPO/MTD/MTTR 概念。

# ⑥ 记忆口诀

> **"恢复先排 BIA 序，冷周温半日热秒级；热站有数同安保，MAA 互帮三患（强/灾/密）。库复三技按 RPO：镜像实时日志时，保管批量丢最多。"**
