# 06 应用密码学与密钥管理（Applied Crypto & Key Management）

> Domain 3 · 把密码学落到邮件/Web/磁盘 + 密钥怎么管才安全

## 一句话秒懂
理论要落地：邮件用 PGP/S-MIME 加密、Web 用 TLS 建安全通道、磁盘用全盘加密。而密钥管理的铁律是——**私钥保密、随机、定期轮换、备份、用 HSM 护**。

## 生活类比
算法是锁芯设计，密钥是钥匙。再好的锁，钥匙满街扔（不保密）、用生日当钥匙（不随机）、一把用到老（不轮换）、丢了没备用的（不备份），照样完蛋。HSM 就是把钥匙锁进保险柜、人不用直接碰。

## 核心概念（大白话 + 原书定义）

### 1. 邮件加密
- **PGP（Pretty Good Privacy）**：Phil Zimmermann 的安全邮件系统，基于"信任网(web of trust)"——你信任的朋友信任的人也可信。现分商业 PGP 与开源 OpenPGP，支持现代算法/哈希/签名。消息常以文本编码（-----BEGIN PGP MESSAGE-----）便于邮件兼容。
- **S/MIME（Secure/Multipurpose Internet Mail Extensions）**：事实标准，用 **RSA** + **X.509 证书**交换公钥；收方用发方证书验证签名。获业界（RSA Security 等）支持，但主流**网页邮箱**默认不支持。

### 2. Web 通信：TLS
- TLS 依靠**服务器数字证书**协商加密通道，目标是建立机密+完整的安全连接。
- 历史：TLS 1.0 基于 SSL 3.0；1.1 有漏洞；**TLS 1.2（2008）是最小安全选项**；**TLS 1.3（2018）安全且更快**。早期 TLS 可降级到 SSL 3.0，2011 年 TLS 1.2 去掉该兼容；现应禁 SSL、只用 TLS。
- 实务：务必确认用的是现代 TLS 而非老旧 SSL。

### 3. 其他应用
- **全盘加密(Full-Disk Encryption)**：保护静态数据，密钥管理是关键。
- **数据库加密、移动设备加密**、高韧性场景（发送方保留副本直至确认收到）。
- **同态加密(Homomorphic Encryption)**：密文上直接做计算，解密结果=明文上计算的结果——可在保护隐私前提下做数据分析。

### 4. 非对称密钥管理最佳实践
1. **选公开且经专家审过的算法**，拒绝"黑盒/隐蔽式安全"。
2. **密钥长度**平衡安全与性能；**确保真随机**（有模式易被破）。
3. **私钥绝对保密**——一旦泄露，该密钥保护的所有过往/现在/未来通信全崩，且他人可冒充你。
4. **定期轮换**（mandatory key rotation），防 undetected 泄露。
5. **备份密钥**（自备或用 key escrow 托管），备份同样要安全。
6. **HSM（硬件安全模块）**：硬件存储管理密钥，人无需直接接触密钥，还提供**硬件加速**。从个人 YubiKey(USB) 到数据中心级产品皆有。

## 真实案例
- **SSL 淘汰**：因 POODLE 等漏洞，现代系统全面禁 SSL、强制 TLS——提醒我们"协议也有保质期"。
- **YubiKey**：把私钥锁在 USB 硬件里，钓鱼也难偷，是 HSM 思想的消费级落地。

## 考试怎么考
- 题型 A：问"最小安全 TLS 版本" → **TLS 1.2**；问"保护隐私又能计算的加密" → **同态加密**。
- 题型 B：S/MIME 依赖 → **X.509 证书 + RSA**；PGP 信任模型 → **Web of Trust**；私钥泄露后果 → 所有使用该密钥的通信失效且可被冒充。
- 必记混淆项：① TLS 1.2 最小安全、1.3 最新；② HSM 防人直接接触密钥+加速；③ 私钥泄露=全盘通信崩；④ 同态加密可算密文。

## 记忆口诀
> **"邮件：PGP 信网、S/MIME 用X.509+RSA；Web：TLS(1.2起、1.3佳、禁SSL)；盘库移：全盘/库/移加密；密钥六律：公开算法、真随机、私保密、常轮换、勤备份、HSM护。"**

## 自测
1. 根据当前标准，可接受的最低安全 TLS 版本是哪个？（答：TLS 1.2；TLS 1.3 更新更安全更快）
2. 硬件安全模块（HSM）在密钥管理中的两个主要作用是什么？（答：安全存储/管理密钥使人无需直接接触密钥，并提供硬件加速提升加密效率）
