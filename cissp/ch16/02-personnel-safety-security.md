# ① 一句话秒懂

人员安全（Personnel Safety and Security）是运营里优先级最高的事——数据、服务器、大楼都能换，人换不了。所以物理安防设计要"人命优先于资产"，再配套胁迫报警、差旅安全和应急管理。

# ② 生活类比

机房出口装了电子密码锁。如果停电时锁**自动锁死**，资产保住了但里面的人可能困死；如果停电时锁**自动弹开**，人能逃命，资产虽有风险但"人比机器重要"。这就是人员安全 > 资产安全的价值观体现。

# ③ 核心概念

## 人员安全高于一切
人不可替换，所有安防控制都应提升人员安全。

## 出口断电行为（经典考点）
考察"断电时出口锁的状态"——安全文化正确的选择是**断电开锁**，优先保人命。

## Duress（胁迫报警系统）
单人值守时用。简单形式：一个按钮发求救。常配**口令词（code phrase）**验证真伪：
- 正常口令（如"Everything is awesome"）= 一切 OK。
- 被罪犯控制时**故意跳过口令**编故事 = 监控方识别异常、派援。
电子密码锁也支持双码：正常码开门、胁迫码开门并触发静默报警。

## Travel（差旅安全）
培训员工：开门前核实身份（如假送餐骗局先打电话前台确认）。
电子设备风险：
- **敏感数据**：设备尽量不带敏感数据；要带就强加密。
- **恶意软件与监控设备**：出境后设备可能被装 malware 或物理监听装置；建议带临时设备，回国后 wipe 重装。
- **免费 Wi-Fi**：可能是 on-path / MITM 陷阱，解密所有流量；应自建连接（手机热点/VPN）。
- **VPN**：用于建立安全连接访问内网资源。

## Emergency Management（应急管理）
自然（飓风/地震）或人为（火灾/恐袭/网络攻击致停电）灾难后的人员安全保障，详见 Ch18 DRP。

## 安全培训与意识（补充话题）
- **内部威胁（Insider threat）**：教育识别与上报可疑行为。
- **社交媒体风险**：过度分享被用于社工攻击，严格隐私设置。
- **2FA 疲劳（2FA fatigue）**：用户厌烦 2FA 想绕过；强调其重要性、提升友好度、讲后果。

# ④ 真实案例

员工出差住酒店，出门吃饭时"看似酒店人员"进房装了系统级 malware 和物理监听设备——只要离开设备几分钟就够。原书建议：始终保持设备物理控制，或带一次性临时设备、回国 wipe 重装，杜绝此类供应链/物理植入风险。

# ⑤ 考试怎么考

- **断电时出口锁应开锁**（人员安全优先）是常考价值观题。
- **Duress system** 与 **code phrase** 的作用（验证是否真被胁迫）。
- 差旅中免费 Wi-Fi = on-path/MITM 风险，应使用 VPN/自建连接。
- 2FA 疲劳是用户绕过 2FA 的现象。

# ⑥ 记忆口诀

> **"人命贵于物，断电锁自开；胁迫有暗语，跳过即呼援；出差别带密，免费 Wi-Fi 莫贪；2FA 疲劳要警惕，内鬼社工防在先。"**
