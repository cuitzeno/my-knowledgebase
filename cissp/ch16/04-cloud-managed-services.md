# ① 一句话秒懂

云托管服务（Managed Services in the Cloud）讲清一件事：上了云，安全责任不是全甩给厂商——**共享责任模型（Shared Responsibility）** 决定了哪些你管、哪些厂商管，再顺带理清 SaaS/PaaS/IaaS、部署模型、弹性伸缩和 serverless 这些云术语。

# ② 生活类比

把云想象成租房：
- **IaaS** = 租了毛坯房（服务器/存储/网络），装修、家具、水电你全管，房东只保房子不塌。
- **PaaS** = 租了带装修带平台的房，你只管往里放自己的"业务应用"，房东管硬件和平台。
- **SaaS** = 直接租精装带家具的房，你只管用自己的数据，房东管一切维护（如 Gmail）。
**共享责任**就是：房东管"房子结构"，你管"你放在屋里的东西和你怎么用"。

# ③ 核心概念

## 云核心挑战
外部云资源**脱离组织直接控制**，风险更难管。敏感数据**全部加密**（传输中 + 静态）。DoD CC SRG 强调：**客户自己管加密、自己控密钥**，不用厂商控的加密——消除厂商内鬼风险，支持密码擦除（cryptographic erase，删密钥即销毁数据）。

## 共享责任模型（Shared Responsibility）
按服务模型划分维护/安全责任：
- **SaaS**：厂商管全部维护；客户共管数据与配置（如 Gmail 账户设置）。
- **PaaS**：厂商管主机与底层基础设施；客户部署/管理自己的应用、部分主机配置。
- **IaaS**：客户提供 OS 与应用并自管维护；厂商只保云基础设施可用。

## 部署模型（Deployment Models）
- **Public（公有云）**：第三方 CSP 托管，谁都能租；用 SLA 保障。
- **Private（私有云）**：单组织专用，可自建（全责）或租用独占（按服务模型分责）。
- **Community（社区云）**：有共同关切（任务/合规）的 2+ 组织共享。
- **Hybrid（混合云）**：2+ 云用技术绑定实现数据与应用可移植。

> NIST SP 800-145 定义云服务/部署模型；SP 800-144 讲公有云安全隐私。

## XaaS 与 SECaaS
- **XaaS（Anything as a Service）**：一切皆服务的统称。
- **SECaaS（安全即服务）**：备份、认证、授权、审计、杀毒、存储、SIEM、IDS/IPS、MaaS（监控即服务）。提供方称 **MSP / MSSP**（托管/托管安全服务商）。

## Scalability vs Elasticity（重要区分）
- **Scalability（可扩展性）**：加资源应对增量负载，**常需人工**（如关机加 RAM），可设计成自动（水平/垂直）。
- **Elasticity（弹性）**：按负载**动态自动**增删资源，无需停机。电商大促时云自动加资源、结束后回收。
> 弹性是"自动动态"，扩展常是"手动或设计自动"——这是高频考点。

## 服务集成（Services Integration / iPaaS）
把本地与云资源 stitch 成无缝环境，消除数据孤岛（data silos），属 SDDC（软件定义数据中心）思路。

## Serverless / FaaS（无服务器 / 函数即服务）
客户管代码，CSP 管底层服务器。函数**仅被调用时运行、完成即终止**，省成本。不同于 PaaS（整个平台常驻、空转也花钱）。类似微服务，各函数独立自治、独立扩展。

# ④ 真实案例

国防部（DoD）用 CC SRG 给 Secret 及以下云资产分 6 个影响级别，并强制"客户自管加密与密钥"——因为若用厂商控的加密，厂商内部人员可能接触明文，且无法用密码擦除干净销毁数据。这是共享责任中"客户必须握紧密钥"的典型体现。

# ⑤ 考试怎么考

- **共享责任**：IaaS 客户管 OS/应用，SaaS 厂商管一切维护，PaaS 居中。
- **四种部署模型**：public/private/community/hybrid。
- **Scalability vs Elasticity**：弹性自动动态、扩展常手动——必考区分。
- **Serverless/FaaS**：按调用运行、CSP 管服务器，省成本 vs PaaS 常驻。
- **客户应自管加密密钥**（尤其政府/敏感数据）。
- SECaaS 提供方 = MSP/MSSP。

# ⑥ 记忆口诀

> **"云分三模责共担：IaaS 你管 OS 与应用，PaaS 你管应用厂管台，SaaS 厂管一切你管数；四部署公有私社区混；弹性自动扩手动，无服务器调才算；密钥握自己手，SECaaS 是 MSSP。"**
