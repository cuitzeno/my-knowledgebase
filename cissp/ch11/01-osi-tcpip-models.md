# 01 · OSI 与 TCP/IP 模型（Ch11 · Domain 4）

> **Domain 4 通信与网络安全**的第一块基石，就是理解网络到底分了几层、每层干什么。考试几乎必考 OSI 七层与 TCP/IP 四层（或五层）的对应关系，以及每层典型的协议和安全关注点。

## ① 一句话秒懂
OSI 和 TCP/IP 都是「把网络通信拆成一层层积木」的模型——下层扛物理传输，上层管应用数据，层与层之间用「封装」套娃。

## ② 生活类比
想象寄快递：你把信纸（应用数据）装进信封（表示/会话层），再套上快递袋（传输层），贴上写有地址的运单（网络层），交给卡车运输（链路层），最后卡车跑在公路上（物理层）。每一层只关心自己那点事，撕掉自己这层「包装」就交给上一层。OSI/TCP/IP 就是这个「分层打包」思想的国际标准版。

## ③ 核心概念（大白话 + 原书定义）

**OSI 七层模型（Open Systems Interconnection）** 从下到上：
1. **物理层（Layer 1）**：比特流的电气/光/无线电传输。中继器、集线器、放大器工作在此层。
2. **数据链路层（Layer 2）**：帧（frame）的成帧、MAC 地址寻址、差错检测。交换机、网桥、NIC 在此层。
3. **网络层（Layer 3）**：逻辑 IP 寻址与路由。路由器在此层。
4. **传输层（Layer 4）**：端到端会话、分段、可靠/不可靠传输。TCP、UDP 在此层。
5. **会话层（Layer 5）**：建立、管理、终止会话。iSCSI 在此层。
6. **表示层（Layer 6）**：数据格式转换、加密、压缩。
7. **应用层（Layer 7）**：用户接口与网络服务。HTTP、FTP、SMTP、DNS 等在此层。

**TCP/IP 模型**（实际互联网用的栈）通常为四层：网络接口层（对应 OSI 1–2）、网际层（对应 3，即 IP）、传输层（对应 4，即 TCP/UDP）、应用层（对应 5–7）。

> 原书定义：*"TCP/IP is a platform-independent protocol based on open standards... it was originally designed for ease of use and interoperability rather than for security."*（TCP/IP 基于开放标准、跨平台，但最初为易用和互通设计，而非安全。）

**关键考试点**：
- 封装顺序示例：`[ Ethernet [ IP [ TCP [ HTTP [数据] ] ] ] ]`，加 TLS 后变成 `[ Ethernet [ IP [ TCP [ TLS [ HTTP [数据] ] ] ] ] ]`。
- 设备分层：Hub/L1、Switch/Bridge/L2、Router/L3、Layer 3 Switch 可路由（L2+L3）。

## ④ 真实案例
某公司内网只用 Hub（L1 设备），结果所有端口处于同一冲突域和广播域，一台中毒机器发出的广播风暴拖垮整网。改用交换机（L2，分割冲突域）并划 VLAN（L2 分割广播域）后，性能与隔离性立刻改善——这正是「懂分层才能选对设备」的实例。

## ⑤ 考试怎么考
- 给一个协议（如 TLS、IP、MAC），让你判断它在 OSI 哪一层。
- 给设备名（Hub/Switch/Router/Bridge），问它工作在哪层、分割什么域。
- 问 TCP/IP 与 OSI 的层数映射关系。
- **高频混淆**：802.11（无线）vs 802.1X（端口认证），前者是无线标准、后者是认证技术，名字像但不是一回事。

## ⑥ 记忆口诀
> **「物数网传会表应，一二三四五六七」**（物理、数据链路、网络、传输、会话、表示、应用）。
> **「Hub 一层、交换二层、路由三层、TLS 夹在四层上」**——设备分层一句话记牢。

## ⑦ 自测
1. 交换机（Switch）工作在哪一层？它分割的是冲突域还是广播域？（答：L2；分割冲突域，VLAN 才分割广播域）
2. TLS 在 OSI 模型中加密的是哪一层之上的载荷？（答：Layer 4 传输层，加密 TCP 载荷）
3. TCP/IP 模型为什么「天生不安全」？（答：为互通和易用设计，安全非首要目标，需额外叠加加密）
