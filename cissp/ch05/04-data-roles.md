# 04 理解数据角色（Understanding Data Roles）

> Domain 1 收尾篇 · 谁对数据负责？一张"身份牌"清单

## 一句话秒懂
数据不是"大家的"，每个经手人都有明确角色：谁拥有、谁保管、谁用、谁决定怎么收集——责任边界清楚了，出事才知道找谁。

## 生活类比
把数据当一栋楼：业主（Owner）定规则、聘物业；物业（Custodian）日常维护巡检；住户（User）只用自己的房间；而 GDPR 体系下还有"开发商/包租公"（Controller 决定用途）和"外包保洁"（Processor 按指示干活）。

## 核心概念（大白话 + 原书定义）

### 1. 数据所有者（Data Owner）
对数据负有**最终组织责任**的人，通常是 CEO、总裁或部门主管。职责（NIST SP 800-18）：
- 确定数据分类并正确贴标；
- 依分类与安全策略定适当控制；
- 定"可接受使用规则(rules of behavior)"——等同于 AUP（可接受使用策略）；
- 决定谁能访问、授予何种权限；
- 若未尽尽职调查致敏感数据受损，可能负过失(negligence)责任。

> 人员须**定期确认**已读并同意 AUP/行为规则（常通过电子签名）。

### 2. 数据保管者（Data Custodian）
所有者把日常技术活**委派**给保管者——通常是 IT 人员/系统管理员。负责：
- 按备份策略妥善存储与保护（如执行备份）；
- 维护审计日志；
- 可能被授权分配数据权限。
保管者保护**完整性与安全**，但不对分类决策负责。

### 3. 用户与主体（Users & Subjects）
- **User（用户）**：经计算系统访问数据完成工作的人，**仅应获工作所需的最小数据**（最小权限）。
- **Data Subject（数据主体，GDPR）**：能被标识符（姓名、ID、位置、在线标识等）识别的自然人。如文件含 Sally Smith 的 PII，Sally 就是数据主体。

### 4. GDPR 双角色：控制者 vs 处理者
- **Data Controller（数据控制者）**：决定"为何处理、如何处理"个人数据的实体（定"how"和"why"），即便自己不动手。
- **Data Processor（数据处理者）**：仅**代表控制者**处理个人数据的组织（如外包的薪资公司）。必须**只按控制者指示**用数据，不得另作他用。
- 例：雇主收集员工信息发工资→雇主是 Controller；把信息交给第三方薪资公司→该公司是 Processor。
- GDPR 违规罚款最高**全球营收 4% 或 2000 万欧元，取高者**。因此许多组织设 **DPO（数据保护官，Data Protection Officer）** 监督合规——GDPR 强制要求相关组织设此角色。

### 5. 系统所有者（System Owner）
对处理数据的**系统**负责（补充角色，Summary 提及）。

## 角色对照表
| 角色 | 核心责任 | 典型人选 |
|---|---|---|
| Data Owner | 分类、贴标、定策略、担责 | CEO/部门主管 |
| Data Custodian | 日常存储/备份/日志 | IT/系统管理员 |
| User | 按最小权限使用 | 员工 |
| Data Controller | 决定处理目的与方式 | 组织本身(GDPR) |
| Data Processor | 按指示处理 | 外包方(GDPR) |
| Data Subject | 被收集数据的个人 | 客户/员工 |
| DPO | 监督隐私合规 | 专职(GDPR 强制) |

## 考试怎么考
- 题型 A：问"谁最终负责确定数据分类" → **Data Owner**。
- 题型 B：GDPR 场景"外包薪资公司只按雇主指示处理员工数据" → 该公司是 **Processor**，雇主是 **Controller**。
- 必记混淆项：① Owner 负终责、Custodian 只干技术活；② Controller 定"目的/方式"、Processor 只执行；③ DPO 是 GDPR 强制角色；④ 罚款上限 4% 全球营收或 2000 万欧。

## 记忆口诀
> **"主(O)定规则、管(C)干维护、用(U)取所需；GDPR 里控(Controller)定调、处(Processor)照办、主(Subject)是被收集的人、DPO 盯合规。"**

## 自测
1. 一家公司把员工薪资处理外包给第三方，依 GDPR，这家第三方公司扮演什么角色？（答：Data Processor 数据处理者）
2. 谁对数据的分类是否恰当、安全策略是否到位承担最终组织责任并可被追责？（答：Data Owner 数据所有者）
